# DUAL TANK v0.4.5 P2P 二人同期リセット

v0.4.4を基準に、P2Pモードの設定画面へ「↺ 最初からやり直す」を追加。

- 操縦手・砲手のどちらからでもリセット可能（操作した側で確認ダイアログ）。
- 砲手からの要求はWebRTC DataChannelでホストに送信。
- ホストが `restartGame()` を使い、戦場全体を新しい状態に初期化。相手にも新しい状態を即時通知。
- WAVE、撃破数、敵、配置、建物、弾薬、HP、弾、爆風、入力操作をリセット。
- P2PルームとWebRTC接続は維持し、再入室不要。ズームはそのまま。
- 従来のRender版 `/` に変更なし。

GitHubでZIP内容をリポジトリ直下に反映し、Renderのデプロイ完了後に `/p2p.html` を再読み込みしてください。
