# DUAL TANK v0.4.2 - P2P コントロール改善
従来の `/` は維持。P2Pの `/p2p.html` に以下を追加しました。

- 全画面ボタンを復活・前面表示。モバイルブラウザの仕様によりフルスクリーンAPIが使えない環境もあります。
- 操縦手の設定画面で「左画面スライド」か「◀ ▶ボタン」を切り替え。
- Rボタンは押している間だけ後退。指を離すと前進へ戻ります（アクセルが0より大きい場合）。フォーカス喪失・タッチ中断でも解除。
- ズーム、P2P、戦闘システムは維持。

GitHubにZIP内ファイルを上書きし、Renderのデプロイを確認後 `/p2p.html` でテストしてください。
