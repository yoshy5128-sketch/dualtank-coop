# DUAL TANK v0.4.8 — 車体・砲塔位置修正、描画範囲調整

v0.4.7を基準に、8枚の戦車画像の本体と砲塔を、画像全体の中心ではなく砲塔リング（旋回軸）基準で描画するよう修正しました。車体と砲塔は独立回転を維持します。

また、画面端の描画判定を厳密なビューポート＋余白に変更し、機種・画角により敵戦車が描画対象から外れないよう改善しました。画像URLもv048へ更新してブラウザの画像キャッシュを区別します。

P2P版は `/p2p.html`。従来のRender版は `/`。操作、同期リセット、敵AI、物理・戦闘処理は変更していません。
