# DUAL TANK v0.4.0 — スマホP2P実験版

**v0.3.5版を残した別ページです。** 現在のオンライン版 `/` はそのまま利用できます。

## 使い方
1. GitHubのリポジトリへ内容をアップロードし、Renderの自動デプロイを待ちます。
2. スマホ2台を同じWi-Fiに接続します。テザリングの場合、スマホAでテザリングをON、スマホBはそこへWi-Fi接続します。
3. 両方で `https://dualtank-coop.onrender.com/p2p.html` を開く（URLは自分のRender公開URLに読み替え）。
4. スマホAは「操縦手」を選び部屋を作成（ホスト）。
5. スマホBは「砲手」を選び同じROOM CODEで参加。
6. P2P接続成功後、砲手側にもゲームが表示されます。

## 仕組み
- Render WebSocket `/p2p-signal` はWebRTCの接続情報（SDP/ICE）の交換にのみ使用します。
- WebRTC DataChannelが張れたあとの操作と状態同期は、2端末間で直接通信します。
- ホスト（操縦手）のスマホが敵AI・衝突・ダメージを計算し、相手の砲手は描画・入力を担当します。
- ルームのゲーム状態はRenderでは計算しません。
- 既存 `/`（旧Renderゲーム）と新 `/p2p.html` は別系統で共存します。

## 制約（重要）
- **完全オフライン未対応**：シグナリングにはRenderへのインターネット接続が必要です。
- STUN/TURNを使わずローカル候補だけで接続を試す実験版です。Android端末・テザリング設定・プライバシー保護設定によっては接続できません。インターネット越しのP2Pにも未対応です。
- ホストは操縦手、ゲストは砲手に固定しています。
- WebRTCの接続性・実機での安定性は未検証です。RenderとChrome等で2台の実機テストが必要です。
- ホスト負荷を測定する診断機能や切断からの自動復帰は今後の課題です。
