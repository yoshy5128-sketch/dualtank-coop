# DUAL TANK v0.3.4 — 分散・距離維持AIテスト版

## 修正点
- 各敵へ戦術セクターを割り当て、正面圧力は原則1台に限定し、残りは左右や後方へ回る目標地点を選びます。
- 迂回地点をプレイヤー周囲360度から選び、最短移動より役割を優先します。
- 建物近傍の射撃可能位置を優先する候補評価を維持し、同じ射撃地点への集中を抑制します。
- 経路探索中でも危険な近距離に入った場合には緊急離脱を優先します。
- プレイヤーを見失った敵が中央へ再集合するフォールバックを撤廃しました。
- 少数敵ウェーブ、砲弾、HP・ダメージ表示、WebSocket協力プレイは変更していません。

## GitHub・Renderへの適用
ZIPを解凍し、リポジトリの**ルート**に同名ファイルを上書きアップロードしてコミットしてください。RenderでAuto Deployが有効ならmain更新後に反映されます。

## ローカル実行
`npm install`、`npm start`。構文チェックは`npm run check`。

※戦術行動の実機プレイ評価は未完了です。遮蔽物を用いた完全な待ち伏せ・連携戦術は今後の改善項目です。
