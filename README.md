# DUAL TANK v0.3.5 — 動作安定化テスト版

v0.3.4の敵AI戦術を保ったまま、以下を最適化しました。

- A*経路探索：最大1回/3フレーム（従来最大2回/フレーム）。
- 障害物経路の再計算：2.8〜4.2秒間隔へ延長。目標地点のセル変更だけで毎フレーム再計算しない。
- 敵の視線判定：個体ごとに約0.2秒間隔でキャッシュ。
- サーバー物理30Hzのまま、状態送信を20Hzに減らしてCPU・WebSocket負荷を抑制。
- ブラウザで敵の位置と砲塔角を補間し、受信の小さなゆらぎを吸収。
- 敵の分散配置、少数ウェーブ、HPゲージ上の大きなダメージ表示、AP/HE、協力プレイは維持。

## GitHub/Render
ZIPを解凍し、中身を既存の `dualtank-coop` のルートへ上書きして `main` にCommitしてください。
Renderが自動デプロイされればオンライン版に反映されます。
