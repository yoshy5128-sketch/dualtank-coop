# DUAL TANK v0.4.7 — リアル戦車オブジェクト組み込み版

今回の更新では、これまでの簡易図形タンクの代わりに、トップダウンのリアル戦車スプライトをゲームへ組み込みました。

- プレイヤー戦車：中戦車風デザイン
- 敵 scout：軽快な軽戦車風
- 敵 normal：標準戦車風
- 敵 heavy：重戦車風
- 敵 sniper：駆逐戦車 / 狙撃車両風
- 砲塔は車体と分離して描画され、これまでどおり独立回転
- 車体の前後が見た目で判別しやすい形状
- 既存のP2P協力プレイ、ズーム、R後退、同期リセットは維持

## 反映先
- P2P版: `/p2p.html`
- 従来版: `/`

## 更新方法
ZIPを解凍し、GitHubの `dualtank-coop` リポジトリ直下へ上書きアップロードして Commit してください。
Render 自動デプロイ後、ブラウザで再読み込みします。

## 注意
今回の変更は主に見た目の更新です。物理判定・当たり判定サイズは従来どおりです。
