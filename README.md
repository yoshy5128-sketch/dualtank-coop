# DUAL TANK v0.4.9 — P2P接続状態の誤判定修正

v0.4.8を基準に、接続の状態管理のみ変更しました。

- RenderのWebSocket (`/p2p-signal`) は接続の情報交換用。ここが閉じても、既存のWebRTC DataChannelが開いていればゲーム継続。
- `peer-left` を受信してもDataChannelが開いているときは接続切断扱いにしない。
- WebRTCの一時的な `disconnected` は最大6秒ほど様子を見て、すぐに切断確定にしない。
- `failed` / `closed` / DataChannelの `close` は実際の接続断として通知する。

戦車グラフィック、砲塔位置、ズーム、操縦、リセット、敵AI、描画速度は変更していません。

## 注意
スマホがスリープした・Wi-Fiが切り替わった・ブラウザが停止した等による実際の切断は発生し得ます。今回は特に、シグナリングだけが切れた場合の誤表示・誤停止を修正しています。
